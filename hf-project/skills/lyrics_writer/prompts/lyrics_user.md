请用「先挖本质 → 定情感映射 → 定主题 → 定核心意象 → 写歌词」的创作逻辑写歌词：
1. 先挖出这个事件背后的人性真相：为什么会发生？暴露了人性的什么？（欲望、认知、贪念、孤独、恐惧……）
2. 定情感映射：这件事映射到哪种普遍情感？（爱情/亲情/努力/奋斗/激情/热爱/回忆/遗憾/震撼/友情）吸引谁听？要不要反差？
3. 提炼一句「主题」，歌词每一句都围绕它，不跑偏
4. 找到一个轻脆的核心意象（泡沫/露水/雪花/薄冰/糖/梦这类轻、脆、美、易碎、抓不住的东西），用它贯穿全曲——举重若轻，用最轻的意象承载最重的情感
5. 表层事件简短带过，深层真相重点展开（占大部分篇幅）
6. 留白：情绪藏在意象背后，让听者自己体会，不直白喊出来
7. 用遗憾美学（若是/可有/不问/别/如果/本该）翻出遗憾感
8. 副歌开头唱核心意象+主题，至少重复3-4次，每次含义更深一层
9. 按目标时长 {target_duration} 秒反推歌词长度（约 1.5 字/秒，{target_chars} 字左右），靠经典结构自然撑出时长，不凑字数
