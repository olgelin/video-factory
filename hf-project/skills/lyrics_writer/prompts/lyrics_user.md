请用「事件 → 情绪」的创作逻辑写歌词：
1. 先抓住这个事件里最戳人的那一种情绪（事件只是外壳，情绪才是灵魂）
2. 表层讲清楚事件，深层映射到普遍的、能引发共鸣的情绪
3. 用遗憾美学（若是/可有/不问/别/如果/本该）翻出遗憾感
4. 用日常意象（海/风/花/星球/白鸽/乌鸦/节拍/光/影子）代替直白情绪词
5. 副歌开头，至少重复3-4次，像流行歌曲一样抓人
6. 对话感，口语化，像在跟一个人说话
7. 长度不限，根据内容自然展开
